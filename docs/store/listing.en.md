## Description

```text
OneLongPage PDF saves the web page you are viewing as a single continuous PDF page: no page breaks, no content cut in half. The page is as tall as the content.

WHAT YOU GET
• The whole page on one page. Text stays selectable and searchable, and links keep working.
• A header at the top with the full URL and the capture date and time, in local time with its UTC offset and in UTC. The file name also includes the date and time.
• Cookie banners and pop-ups are hidden before the capture and restored afterwards. The extension never clicks "accept" or "reject". You can turn this off.
• Lazy images and content load before the capture.
• Web apps that scroll inside an inner panel are unrolled, so you get all of the content, not only the visible part.
• Paper width (A4, Letter, A3, A5 or narrow), margin and background options.
• Keyboard shortcut (Alt+Shift+P) and right-click menu.
• English and Spanish.

PRIVACY
The extension does not connect to any server: no analytics, no telemetry, no account. Your pages and PDFs never leave your computer. The source code is public.

ABOUT THE CHROME WARNINGS
To make a PDF page as tall as the content, the extension uses Chrome's built-in PDF engine through the debugger API. No other extension API can print with a custom page size. Because of that:
• When you install it, Chrome warns that the extension can read and change data on websites. It only acts on the tab you capture, when you click the button, the shortcut or the menu.
• During a capture, Chrome shows a bar saying that OneLongPage PDF started debugging the browser. It goes away when the capture ends. If you cancel it, the capture is cancelled.

LIMITATIONS
• It does not work on protected Chrome pages (chrome:// pages, the Chrome Web Store, the PDF viewer).
• Close DevTools on the tab before capturing.
• Chrome cannot create pages taller than about 23 m. Some PDF viewers, such as Adobe Acrobat, limit pages to about 5 m (200 inches); Chrome's viewer does not.
• Content inside iframes from another site, and rows that "virtualized" lists have not drawn yet, are captured as they appear on screen.

Source code and issue tracker: https://github.com/josefuentes4096/onelongpage-pdf
```
