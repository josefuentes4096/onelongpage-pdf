## Name

Taken from the package (`extName`): **OneLongPage PDF**

## Summary

Taken from the package (`extDescription`, 111 of 132 characters):

> Guarda páginas web en un PDF de una sola página continua, sin cortes, con la URL y la fecha/hora de la captura.

## Description

```text
OneLongPage PDF guarda la página web que estás viendo en un PDF de una sola página continua: sin saltos de página y sin contenido cortado por la mitad. La página mide lo que mide el contenido.

QUÉ OBTIENES
• Toda la página en una sola página. El texto se puede seleccionar y buscar, y los enlaces siguen funcionando.
• Una cabecera arriba con la URL completa y la fecha y hora de la captura, en hora local con su diferencia respecto de UTC y en UTC. El nombre del archivo también incluye la fecha y la hora.
• Los avisos de cookies y las ventanas emergentes se ocultan antes de la captura y se restauran después. La extensión nunca pulsa "aceptar" ni "rechazar". Puedes desactivarlo.
• Las imágenes y el contenido diferidos se cargan antes de la captura.
• Las aplicaciones web que se desplazan dentro de un panel interno se despliegan, así obtienes todo el contenido y no solo la parte visible.
• Opciones de ancho de papel (A4, Carta, A3, A5 o estrecho), margen y fondos.
• Atajo de teclado (Alt+Mayús+P) y menú del clic derecho.
• En español e inglés.

PRIVACIDAD
La extensión no se conecta a ningún servidor: sin analítica, sin telemetría y sin cuenta. Tus páginas y tus PDF nunca salen de tu computadora. El código fuente es público.

SOBRE LOS AVISOS DE CHROME
Para crear una página de PDF tan alta como el contenido, la extensión usa el motor de PDF de Chrome a través de la API del depurador. Ninguna otra API de extensiones permite imprimir con un tamaño de página a medida. Por eso:
• Al instalarla, Chrome avisa de que la extensión puede leer y cambiar datos de los sitios web. Solo actúa sobre la pestaña que capturas, cuando pulsas el botón, el atajo o el menú.
• Durante la captura, Chrome muestra una barra que dice que OneLongPage PDF empezó a depurar el navegador. Desaparece al terminar la captura. Si la cancelas, se cancela la captura.

LIMITACIONES
• No funciona en páginas protegidas de Chrome (páginas chrome://, Chrome Web Store, el visor de PDF).
• Cierra DevTools en la pestaña antes de capturar.
• Chrome no puede crear páginas de más de unos 23 m de alto. Algunos visores de PDF, como Adobe Acrobat, limitan las páginas a unos 5 m (200 pulgadas); el visor de Chrome no.
• El contenido de iframes de otro sitio y las filas que las listas "virtualizadas" todavía no dibujaron se capturan tal como se ven en pantalla.

Código fuente y reporte de problemas: https://github.com/josefuentes4096/onelongpage-pdf
```
